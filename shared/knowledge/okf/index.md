# OKF — Organised Knowledge Folder

Durable project knowledge. Everything here carries YAML frontmatter with
provenance, authority, and status. Nothing here is current truth by
default — `PROJECT_STATUS.md` is.

| Area | Contents |
|------|----------|
| `domains/` | Subject-area knowledge (IDA/idalib, PE format, x86/arm64, Ollama, Neo4j) |
| `systems/` | This stack's own architecture (pipeline, MCP, phantomrt) |
| `datasets/` | Test binaries, corpora, fixtures |
| `decisions/` | Approved decision records |
| `episodes/` | What happened — episodic memory |
| `relationships/` | Cross-record link notes |
| `playbooks/` | How-to procedures, incl. `agent-failure-patterns/` |
| `references/` | External references |

Write path: draft → propose → human review → approved. See
`_config/memory-policy.yaml`.
