# false-completion-claim

**What happens:** Success was claimed without evidence.

**Required behaviour:** Completion requires validation: tests run, commands executed, outputs shown. Report evidence, not vibes.

**If you notice it happening:** stop, record an episodic record
(`shared/templates/episodic-record.template.md`), and surface it to the user.
