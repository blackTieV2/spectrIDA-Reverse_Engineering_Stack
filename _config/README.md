# _config/

Canonical policies. Agents READ these; they may propose changes but must not
silently rewrite them. Proposals go through human review (see
`_config/memory-policy.yaml` §promotion).

- `authority-policy.yaml` — who/what outranks what
- `memory-policy.yaml` — the five memory classes, promotion, sensitivity
- `retrieval-policy.yaml` — how recall works and why it is never authority
- `tool-profiles.yaml` — what each stage's agent may touch
