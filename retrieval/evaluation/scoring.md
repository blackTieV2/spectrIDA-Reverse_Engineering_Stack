# Scoring

Measure per golden-set run:

- Recall@K, Precision@K
- authority correctness, freshness correctness, supersession correctness
- provenance correctness, sensitivity compliance
- stale leakage, false positives
- latency, token cost
- **Dangerous Authority Error Rate** — a historical/supporting/candidate/
  semantic memory caused an incorrect CURRENT operational instruction.
  Target: approximately zero. This metric outranks all others.

Collect `retrieval-feedback` records first; retune only on evidence.
